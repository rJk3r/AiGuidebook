Формула промпта

1Роль

«Ты — UX-дизайнер», «Ты — бариста с 10-летним стажем».

2Контекст

Аудитория, продукт, ситуация, известные факты.

3Задача

Конкретное действие без воды: «создай», «сократи», «сравни».

4Ограничения

Объём, стиль, что нельзя менять, что нельзя выдумывать.

5Формат

Список, таблица, JSON, письмо, план, код.

6Критерий

Как проверить, что ответ хорош.

Эволюция промпта: от плохого к хорошему

❌ Шаг 1. Мусорный запрос

Напиши пост про кофе.

Результат: «Кофе — популярный напиток. Он бодрит и имеет богатую историю…»

❌ Шаг 2. Добавили стиль, но нет роли

Напиши пост о кофе для соцсетей в дружелюбном стиле.

Результат: чуть живее, но всё ещё шаблон.

✅ Шаг 3. Добавили роль и контекст

Ты — бариста с 10-летним опытом. Напиши пост для соцсетей (до 300 слов) о том, почему ты любишь кофе. Личный стиль, от первого лица.

✅ Шаг 4. Точное ТЗ

Ты — бариста с 10-летним стажем. Напиши пост для соцсетей (до 300 слов) о различиях арабики и робусты. Добавь метафору, лёгкий юмор, обращайся к аудитории на «ты». Избегай канцеляризмов.

Контент и маркетинг

# Контент-план для Instagram
Составь контент-план для [бренд: студия красоты "Vibe"] на [месяц: июнь].
Услуги: маникюр, педикюр, архитектура бровей, ресницы, перманент, парикмахер.
Периодичность: 7 постов в неделю.
Соотношение по цели: 30% продающие, 30% полезные, 40% вовлекающие.
Соотношение по формату: 60% Reels, 30% карусель, 10% IGTV.
Тон: неформальный, прямой, заботливый. Обращение на «ты».
Таблица: Дата | Цель | Формат | Заголовок-кликбейт | Краткое описание.
Не придумывай кейсы и цифры.
# Сценарий Reels по формуле P.O.P.P
Действуй как сценарист Reels. Используй формулу:
P — Проблема: «Ты не создашь хороший контент-план без…»
O — Возможность: «Создать контент-план можно за 2 минуты…»
P — Практические шаги: перечисли пошагово.
P — Обещание: гарантия результата + призыв подписаться.
Тема: [вставь тему].
Хронометраж: до 30 секунд.
# Ценностное предложение

# Описание товара для маркетплейса

Не добавляй отзывы и свойства, которых нет во входных данных.

[вставьте текст]

Не добавляй новых утверждений.

# Редактура с сохранением голоса автора

[вставьте текст]

Не добавляй пафос, клише и факты от себя.

# Упрощение сложного текста

Аналитика и исследования

# Анализ таблицы
Проанализируй таблицу: [данные или описание столбцов].
Цель анализа: [вопрос].
1. Проверь пропуски, дубли, несопоставимые значения.
2. Покажи ключевые изменения, аномалии, возможные объяснения.
3. Не выдавай корреляцию за причину.
4. Предложи, какие данные нужны для проверки гипотезы.
# Поиск причин проблемы
Разбери проблему: [описание].
Факты: [список]. Когда началось: [дата]. Что менялось: [события].
Сформулируй несколько конкурирующих объяснений.
Для каждого — подтверждающие и опровергающие признаки.
Предложи самый дешёвый и безопасный способ проверки.
# Проверка аргументации
Проверь аргументацию текста: [вставьте текст].
Выдели: главный вывод, посылки, скрытые предположения, доказательства.
Найди логические скачки и альтернативные объяснения.
Не спорь со стилем — оценивай только обоснование.

Параметр Strength (для Image-to-Video)

0.4

Минимальное изменение, максимальное сохранение исходника. Для портретов и архивных фото.

0.45

Оптимум для портретов с людьми. Баланс сохранения и движения.

0.5

Баланс для пейзажей и предметной съёмки.

> 0.6

Лицо начинает меняться непредсказуемо. Избегать для портретов.

Типичные ошибки Как не надо

Самые частые грабли, на которые наступают новички. Коротко и по делу.

❌ Слишком общий промпт

Напиши статью. / Красивая картинка. / Эпичное видео.

Результат: банальность, «пластиковый» контент, артефакты. Добавляйте роль, контекст, ограничения.

❌ Нет контекста и аудитории

Напиши пост о новом продукте.

Вместо этого: «Энергичный пост для молодёжной аудитории о беспроводных наушниках [бренд]».

❌ Рано сдаться после первой попытки

Промт-инжиниринг — это 3–5 итераций. Первый ответ почти никогда не финальный. Уточняйте, переформулируйте, добавляйте детали.

❌ Видео: слишком много действий в одном промпте

Один тип движения на клип: либо камера, либо объект. Смешивание сложных действий = артефакты и морфинг.

❌ Видео: нет негативного промпта

Всегда указывайте, чего избегать: без резких движений, без текста, без артефактов, без деформированных лиц. Снижает число неудачных генераций вдвое.

❌ Видео: «ожидать текст в кадре»

Большинство моделей плохо генерируют читаемый текст. Надписи накладывайте при монтаже.

❌ Видео: Strength > 0.6 для портретов

Лицо начинает меняться непредсказуемо. Для людей держите 0.4–0.45.

❌ Видео: дёрганая камера

Добавляйте: slowly, gently, smoothly, stable composition. Медленное движение предотвращает артефакты на всех моделях.

❌ Картинки: нет указания камеры и света

Без 85mm f/1.2, golden hour, rim light — получите усреднённую «пластиковую» картинку.

❌ Текст: ИИ выдумывает факты

Всегда добавляйте: Не придумывай кейсы и цифры. Работай только по источнику. И проверяйте факты по первоисточникам.

❌ Текст: нет формата ответа

Указывайте: таблица / JSON / список / письмо / план и обязательные поля. Иначе получите «простыню» без структуры.
